# AMK ERP (with Upstage Solar AI Agent)

AMK 맞춤형 차세대 올인원 ERP 플랫폼입니다.

## 🚀 주요 기능
- **📅 업무 공유 & 캘린더**: 일간, 주간, 월간 뷰 및 칸반 보드 연동
- **⏰ 스마트 근태 관리**: 사내 네트워크/IP 기반 출퇴근 체크 및 근무 현황, 간이 전자결재
- **📦 amk-inventory 연동**: 기존 재고관리 프로그램과의 실시간 재고 조회, 안전재고 부족 알림, 입출고 일정 동기화
- **🤖 Upstage Solar AI Agent 챗봇**:
  - 한국어 특화 자연어 대화를 통한 일정 등록, 근태 체크, 재고 조회/제어 지원 (Function Calling)
- **📊 통합 대시보드 & 모바일 PWA 지원**
